# Audrey Travel OS 1.0

Released 24 October 2026.

Audrey Travel OS helps plan, experience, remember and learn from travel. Version 1.0 is the first complete release spanning the full trip lifecycle.

## Plan

- Create and manage road trips, flight based holidays and mixed itineraries.
- Browse hiking, cycling, skiing and water routes.
- Enrich Garmin FIT courses with selected route points and weather alerts.
- Discover relevant local interests and events around each stay.

## Travel

- Use weather, route, snow, tide, pass and vehicle context while travelling.
- See a context aware Today recommendation using location, conditions and Garmin readiness.
- Monitor motorhome telemetry, habitation door, LPG and journey information.

## Capture

- Save Moments by type, rating, comment, location and optional cover photo.
- Capture spoken notes from an iPhone Shortcut.
- Import Garmin activities while retaining their original activity classification.

## Reflect

- Build deterministic Daily Stories, trip timelines and Trip Reviews.
- Explore the interactive journey map and Moments.
- Export a compact Travel Storybook PDF with a chosen hero image.

## Learn

- Summarise the themes, defining Moments and activities that shaped a trip.
- Provide the foundation for a future cross trip Travel Profile and annual review.

## Release hardening

- Filters supermarkets, generic accommodation and routine utility businesses from local interest suggestions.
- Removes the obsolete Wrangler configuration that caused a Cloudflare warning.
- Records a tested rollback point for both the web app and Apps Script backend.

The GitHub repository names remain unchanged to preserve deployment links and history. The product is now formally named **Audrey Travel OS**.
